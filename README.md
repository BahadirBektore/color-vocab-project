# Color Vocab Project

The **Color Vocab Project** is a front-end web application that visually teaches color names through interactive cards.  
This project demonstrates use of **HTML**, **CSS**, and **JavaScript** to create a responsive and educational interface.

---

## 🌐 Live Demo

Try it here:  
👉 https://bahadirbektore.github.io/color-vocab-project/

---

## 🚀 Project Overview

This project includes:

- A set of color cards with corresponding names  
- Clean and readable layout  
- Responsive design for different screen sizes  
- Interactive and visual UI elements

---

## 🛠 Technologies Used

This project was built using:

- **HTML5** – Semantic structure  
- **CSS3** – Styling and layout  
- **JavaScript** – Dynamic interaction

---

## 📋 How to Use

1. Open the live demo link above.  
2. Browse through the color cards.  
3. Learn color names with a visually engaging layout.
